# 検討の手順と分岐（1.17.0 / 26）

過去の局面で別の手を指しても、それまでの続きは削除しません。「手順」から開く「手順・分岐」に、元の手順と分岐を接続線・分岐番号で表示します。65手目に3通りの手を指した場合は、各65手目に1/3〜3/3を表示します。

任意の手を選ぶと、その局面・持ち駒・手番・評価値へ移動します。「次へ」「最終」と評価グラフは、選択した分岐の続きを表示します。分岐の中でさらに分岐しても保持し、同じ続きの手を再び指した場合は既存の枝を再利用します。異なる経路で同じ局面に到達しても経路を混同しません。

現在の検討ツリーと選択中の局面は端末内へ保存し、アプリ再起動後も復元します。既存の直線的な履歴は初回使用時に移行します。Androidでは過去の300操作による履歴の切り捨てを廃止しました（盤面を戻す作業用キャッシュは300操作のままですが、それ以前の局面も手順から復元できます）。以前のバージョンですでに削除された手順の復元はできません。

取り込んだ元の棋譜・対局のアーカイブは独立したままです。別の棋譜への置き換えは従来どおり現在の検討ツリーを置き換えます。この変更でストア審査中の1.16.0（25）を差し替えたり、一般公開したりはしません。審査の自動確認は所有者の指示で削除済みです。

検証は、Shogi Questの実際の79手棋譜から64手目まで戻して3つの65手目を作り、各枝の終端・入れ子分岐・枝別評価値・再起動保存・旧形式の移行を確認します。AndroidのネイティブUIテストでは、再起動後に手順ダイアログの各枝を選び、盤面と最終局面を確認・撮影します。iOSは同じ棋譜による永続化テストを既存Xcodeテストに追加しています。
